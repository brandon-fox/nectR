# Design: Hive Persistence, Deterministic WAL Snapshots, CQRS Graph Read Model & FastAPI (`hive-persistence-api`)

## DDD Ports & Adapters
- **`HiveRepositoryPort` (Hexagonal Port):** Abstract protocol in `src/nectr/services/ports.py` for loading/saving `BeeAccount`, `ServiceBarterSession`, `HiveState`, and sequential block logs.
- **`SQLModelHiveRepository` (Adapter):** Implements `HiveRepositoryPort` using `sqlmodel.Session` and `alembic`-managed tables (with single-writer SQLite WAL snapshot discipline, banning non-deterministic SQL functions such as `now()`, `CURRENT_TIMESTAMP`, and `random()`, deriving all timestamps strictly from verified `BlockHeader.timestamp`). Under `ADR-0017`, persists canonical immutable `PoUW-PoW` blocks and signed `vyper` `.vy` transactions (`secp256k1` `eth-account`, `DEC-019`) so reloading deterministically replays the block log into zero-gas `py-evm` and verifies `evm_state_root` while projecting fast `BeeAccount`/`ServiceBarterSession` read views.
- **`PostCommitEventBus` & `CQRSGraphProjector` (Read-Model Adapter):** Emits immutable post-commit domain events (`PollenAllocated`, `WorkerCertified`, `BarterEscrowed`, `SessionSettled`, `DisputeResolvedToComb`, `AcceptedStatusGranted`) after block commit to update off-chain `networkx` / `NetworKit` / `rustworkx` views asynchronously while keeping on-chain consensus state restricted to `evm_state_root` + 32-byte `knowledge_graph_root` (`ADR-0014`, `ADR-0017`).
- **`FastAPIHiveRouter` & PactFlow Contract Gate (Driving Adapter, `ADR-0018`):** Maps HTTP requests to `HiveServiceLayer` commands and read-model queries (converting `uint256` `micro_nectr` and `0..10,000 bps` at the API boundary per `DEC-017`/`DEC-018`), verified via `pact-python` v4 consumer HTTP/async message pacts offline and **PactFlow** Bi-Directional OpenAPI 3.1 + `can-i-deploy` gates in CI.
- **`TelemetryAdapter` (`structlog` + `opentelemetry-sdk`):** Binds `hive_id`, `epoch`, and `tx_id` context and exports OTLP metrics (PoUW solve/verify latency, block interval, Comb ratio) with zero secrets or FERPA/GDPR PII (`ADR-0009`, `ADR-0015`).

## Invariants
1. **Purity of Contracts:** `src/nectr/contracts/` MUST NOT import `sqlmodel`, `fastapi`, `structlog`, `opentelemetry`, or `networkx`.
2. **Transactional Atomicity & Deterministic Replay:** State transitions in `HiveContractEngine` commit atomically to storage; replaying an ordered genesis + block log across any two university VMs produces bit-identical state roots.
